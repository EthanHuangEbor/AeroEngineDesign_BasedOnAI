# MTA-VHEP 推进系统概念设计 — 摘要

## 问题

中型运输机（25 t 有效载荷、3200 km 航程）需要在燃油效率、短距起降能力和推进系统架构之间取得平衡。传统双流道涡扇发动机在低速增升和全包线效率方面存在固有限制。

## 架构

MTA-VHEP 采用 **双台三流道变循环涡扇 + 四台电动吹气襟翼风扇**的混合推进架构：
- **主推进**：2 台三流道变循环涡扇，通过第三流道旁通和可变几何实现全包线多模式高效运行
- **电动增升辅助**：4 台电动吹气襟翼风扇，在起飞、初始爬升和进近阶段提供短时推力辅助，巡航期间关闭

## 概念级模型链

V0.2 已完成端到端概念计算链：
配置 → 大气/燃料/气动 → 发动机代理 → 混合电系统 → 任务求解器 → 约束诊断 → 敏感性分类

225 个敏感性案例覆盖了 10 个设计变量的参数空间扫描。

## 关键输出

| 指标 | 值 |
|------|-----|
| 任务求解器方案数 | 3（baseline / adaptive / hybrid） |
| 敏感性总案例数 | 225 |
| 进近模型敏感案例数 | 104（原始进近约束受模型公式选择影响） |
| 仅进近修正候选数 | 92（诊断性筛选，非最终可行设计） |
| 全段修正可行设计数 | **0**（非进近段约束仍然存在） |
| 主导剩余约束 | 下降段（197行）、起飞段（28行） |
| 混合电未满足电负荷行数 | 69 |

## 约束

V0.2 **未产生全段可行的验证设计点**。主要剩余约束：
1. **下降段推力裕度**（197/225 行）：怠速代理推力无法满足下降段阻力平衡
2. **起飞段推力裕度**（28/225 行）：部分高电功率案例中轴功率提取 penalty 影响
3. **混合电未满足电负荷**（69/225 行）：进近段电动风扇 assist 功率超电池/发电机供给能力
4. **MTOW sizing 未闭合**：混合电方案接近 V0.1 上限（95000 kg）

## 价值

尽管全段可行设计为 0，V0.2 完成了概念设计的核心诊断工作：
- 建立了可审计的完整计算链
- 区分了模型公式敏感约束（104 行）和实际设计约束
- 确定了约束消解的优先级和方向
- 自适应循环方向性燃油趋势为条件性模型趋势（非验证收益）

## 下一步

**V0.3 sizing/细化**：下降段推力模型修正 → 非进近约束消解 → MTOW 尺寸迭代 → 混合电功率调度优化 → 低速度气动验证

**声明**：V0.2 为概念设计模型。不得声称已验证的燃油消耗降低、认证航程、STOL 能力、噪声降低或最终可行方案。
