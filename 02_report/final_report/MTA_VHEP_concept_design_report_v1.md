## 摘要

MTA-VHEP（Medium Transport Aircraft — Variable-cycle Hybrid-Electric Propulsion）是面向 25 t 有效载荷、3200 km 设计航程中型运输机的推进系统概念设计方案。本方案采用**双台三流道变循环涡扇发动机**作为主推进力，辅以**四台电动吹气襟翼风扇**提供低速增升辅助，通过第三流道旁通和可变几何实现全包线多模式高效运行。

V0.2 概念设计阶段已建立完整的端到端计算链，涵盖配置定义、大气/燃料/气动建模、发动机代理、混合电系统、准稳态任务求解器、约束诊断和 225 行敏感性参数扫描。三级约束分类体系（原始约束、仅进近修正约束、全段修正约束）已建立并完成内部一致性审计（名义回放 3/3 通过，推力单调性 6/6 通过）。

**核心诊断结论**：V0.2 尚未产生全段可行的验证设计点。225 个敏感性案例中，104 个案例的原始进近约束与模型公式选择有关，92 个案例在仅进近修正后通过诊断性筛选，但全段修正后可行设计数为 0——下降段怠速代理推力模型（197 行限制）和混合电未满足电负荷（69 行）构成剩余约束。自适应循环方向性燃油趋势为条件性模型趋势（非验证收益）。

架构在概念层面保持技术前景。下一步 V0.3 应聚焦于 sizing/细化：非进近推力裕度消解、下降段/起飞段模型修正、混合电功率调度优化、低速度气动验证和重量组成迭代闭合。

**声明**：V0.2 为概念设计模型，所有性能数据为概念级模型输出，**不得声称**已验证的燃油消耗降低、认证航程、STOL 能力、噪声降低或最终可行方案。

### 2.1 基准平台参数

| 奥斯瓦尔德效率 | 0.78 | 估算值 | Engineering Inference |

| 构型 | CD0 | k | 备注 |
|------|-----|---|------|
| Clean | 0.026 | — | 巡航构型 |

### 2.2 方案选择逻辑

MTA-VHEP 的构型选择遵循"主推进通过燃油、增升辅助通过电功率"的能量分配原则：

1. **主机为全航段能量核心**：两台三流道变循环涡扇提供起飞到着陆的全包线推进。3,200 km 航程的全部能量来自燃油化学能转化。
2. **电动风扇为短时增升辅助**：四台电动吹气襟翼风扇在起飞、初始爬升和进近阶段提供短时（总计约 540 s）推力辅助，不承担巡航推进任务。电动风扇的峰值功率来自发电机轴功率提取和电池缓冲的联合供给。
3. **混合电权衡**：电动风扇提供增升收益（更高的有效 CLmax、吹气襟翼效果），但代价是混合电系统质量惩罚（约 4,200 kg）和轴功率提取对主机推力的 penalty。V0.2-05 敏感性分析评估了该权衡的参数空间。

**不选择纯电动方案**：3,200 km 航程所需能量（约 40–50 MWh）远超当前航空电池技术的能力范围（约 250–300 Wh/kg 的电池级能量密度意味着约 150 吨电池重量）。

**不选择液氢基准方案**：液氢燃料存储在运输机领域面临体积约束（液氢密度为 Jet-A 的 1/4）和低温基础设施挑战，当前 TRL 1–2。

**能量流**：
1. 主机燃烧 Jet-A 产生机械推力（主推进）

## 4 三涵道变循环涡扇概念设计

### 4.1 变循环原理

三流道变循环涡扇发动机通过可变几何导流叶片、可调压气机和第三流道（third-stream）旁通机构实现单台发动机在全包线的多模式高效运行：

- **第三流道**：在低功率需求时旁通部分气流，改善喘振裕度；在高功率需求时增大主流道流量
- **可变喷管**：调节喷口面积以适配不同推力需求
- **联合调度**：油门、导流叶片、第三流道开度和喷管面积协调调节

### 4.2 工作模式调度

| 模式 | 油门 | 第三流道调度 | 可变喷管调度 |
|------|------|-------------|-------------|
| 起飞 | 1.00 | 0.10 | 0.85 |
| 爬升 | 0.88 | 0.15 | 0.70 |
| 巡航 | 0.65 | 0.40 | 0.55 |
| 进近 | 0.35 | 0.50 | 0.45 |
| 怠速 | 0.10 | 0.30 | 0.40 |

### 4.4 轴功率提取效应

每从主机提取 1 MW 轴功率，产生约 19.8–39.7 kN 推力损失，同时燃油流量增加约 +0.006 kg/s。

| 设计点 | 抽功 (W) | 净推力 (N) | 推力损失 (N) |
|--------|---------|-----------|-------------|
| 起飞 | 0 | 114,873.6 | 0 |
| 起飞 | 1,000,000 | 75,191.0 | 39,682.5 |
| 爬升 | 1,000,000 | 46,275.2 | 16,882.2 |
| 进近 | 500,000 | 17,734.9 | 19,841.3 |

混合电方案中，起飞阶段每台发动机抽功约 1.06 MW，产生约 42.2 kN 推力损失。这是混合电系统的核心耦合 cost。

### 4.5 模型局限性

V0.2 发动机代理模型**不是**部件级热力学循环模型（如 GasTurb、NPSS），而是使用 YAML 配置 TSFC 和参数化调度乘子的概念级代理。第三流道效应、可变喷管效果和轴功率提取 penalty 均为参数化估算。

**不证明**：认证级发动机性能、真实喘振裕度、真实轴系匹配。

### 5.5 模型局限性

- 风扇推力为功率-速度代理（P/v），非 CFD 或风洞验证
- 吹气襟翼增升系数为代理，非气动仿真输出
- 电气总线为准稳态（无瞬态响应模型）
- 电池为集总参数（无内部温度分布、倍率效应和老化模型）
- 热管理为集总估算（非换热器设计）
- 发电机抽功使用 V0.2-02 功率等价代理

**不证明**：STOL 改进、噪声降低、认证级安全设计。

## 7 概念级仿真模型与边界

### 7.1 模型层级总览

MTA-VHEP V0.2 建立了五层概念级仿真模型链：

```
┌──────────────────────────────────────────────┐
│ L1: 大气/燃料/气动                            │
│ ISA Atmosphere, Jet-A Properties, Drag Polar  │
│ 来源: YAML 配置 + 概念公式                    │
├──────────────────────────────────────────────┤
│ L2: 发动机代理模型                            │
│ TSFC Surrogate, Thrust Lapse, Power Extraction │
│ 来源: YAML TSFC 占位符 + 参数化调度乘子        │
├──────────────────────────────────────────────┤
│ L3: 混合电系统                                │
│ SOC Timeline, Electric Bus, Thermal Load       │
│ 来源: 集总参数模型 + 功率等价代理              │
├──────────────────────────────────────────────┤
│ L4: 任务求解器                                │
│ Segmented Mission Solver, Constraint Reporter  │
│ 来源: 准稳态分段方法                          │
├──────────────────────────────────────────────┤
│ L5: 诊断与敏感性分类                           │
│ Constraint Diagnostics, Sensitivity Scan,      │
│ 3-Tier Constraint Classification               │
└──────────────────────────────────────────────┘
```

### 7.2 L1: 大气、燃料与基础气动

- **ISA 大气模型**：0–12 km，简单对流层 lapse rate 模型。非认证级大气模型
- **燃料性质**：Jet-A / SAF 密度、热值查询。SAF 为场景模型，非生命周期碳排放认证
- **概念阻力极曲线**：CD = CD0 + k × CL²。CD0 为占位符（0.026 clean），非 CFD/风洞
- **起落架阻力**：ΔCD = +0.020 占位符

### 7.3 L2: 发动机代理模型

- 非部件级热力学循环模型
- TSFC 来自 YAML 配置占位符
- 第三流道/可变喷管效应为参数化调度乘子
- 轴功率提取 penalty 为功率等价代理

### 7.4 L3: 混合电系统

- 电动风扇推力为 P_shaft/v 代理
- 电气总线为准稳态模型
- 电池为集总参数，SOC 0.20–0.90
- 热管理为集总估算

### 7.5 L4: 准稳态任务求解器

- 分段方法（非轨迹优化）
- 每段内参数不变
- 爬升/下降为简化模型
- 进近段模型经过 V0.2-04S 审计和 V0.2-05Q2 修正

### 7.6 L5: 诊断与敏感性分析

- 三级约束分类：原始 / 仅进近修正 / 全段修正
- 225 行 OAT + 网格扫描
- 名义回放一致性 3/3 通过
- 推力单调性 6/6 通过

### 7.7 认证边界

MTA-VHEP V0.2 模型**不得**用于以下用途：

| 禁止用途 | 原因 |
|----------|------|
| 适航认证 / 型号合格审定 | 概念设计模型，非认证等级 |
| 最终性能保证 | 所有输出为概念级代理/占位符 |
| CFD/风洞等效替代 | 阻力极曲线和增升系数为概念公式 |
| 部件级发动机设计 | 代理模型非热力学循环模型 |
| 安全认证 / 故障树分析 | 无故障安全分析模型 |
| 碳排放核算 / 碳中和声明 | 无生命周期碳排放模型 |

### 8.6 约束讨论

#### 下降段约束（197 行，87.6%）

下降段为最顽固的非进近约束。怠速代理推力（约 11,500–12,000 N）无法满足下降段气动阻力（含着陆襟翼 CD0=0.109 和起落架 ΔCD=+0.020 的构型）对可用推力的需求。下降段推力裕度约 −36,000 至 −42,000 N。非进近约束分析将全部 197 行的疑似驱动因子标注为 `descent_surrogate_idle_drag_balance`，表明这是代理模型假设问题而非设计参数问题。

#### 起飞段约束（28 行，12.4%）

部分混合电高电功率案例中，轴功率提取 penalty 导致起飞可用推力不足，起飞段成为全段修正限制段。

#### 混合电未满足电负荷（69 行）

混合电方案在进近段电动风扇 Assist 模式（4 × 1 MW）下，总电功率需求超过发电机（每台抽功受推力 penalty 限制）和电池（SOC 限 0.20）的联合供给能力。未满足电负荷主导值约 287,117 Wh。

#### 混合电质量惩罚

混合电系统质量约 4,200 kg（固定质量 1,200 kg + 功率质量 1,000 kg + 电池质量 2,000 kg）导致 MTOW 增加（hybrid 约 93,643 kg，距 95,000 kg 上限仅余 1,357 kg）和起飞代理指标恶化（hybrid 9,405 vs baseline 7,858）。

#### MTOW sizing 未闭合

全部方案超出初始 MTOW 87,500 kg，hybrid 方案尤为紧张。MTOW sizing 迭代是 V0.3 的核心任务之一。
