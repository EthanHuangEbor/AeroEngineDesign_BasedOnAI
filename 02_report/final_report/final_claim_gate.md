## B. 条件性声明

以下声明**仅可在附带显式限定条件时呈现**，不得作为独立结论：

| 序号 | 声明 | 限定条件 | 允许呈现方式 |
|------|------|----------|-------------|
| B01 | 自适应循环方案显示燃油节省趋势 | 条件性模型趋势，依赖于 YAML 代理 TSFC 假设 | "conditional model trend, not verified benefit" |
| B02 | 混合电辅助可降低起飞场长 | 电动风扇推力为 P/v 代理，非 CFD/风洞验证；当前受质量惩罚限制 | "概念级方向性趋势" |
| B03 | 进近模型修正改善了对原始约束信号的理解 | 修正仅影响进近段约束判断，非进近段约束不变 | "改善约束分类精度" |
| B04 | 仅进近修正候选指示了有前景的设计方向 | 候选为诊断性筛选输出，非进近段约束仍未消解 | "screening output, not validated design" |
| B05 | 225 行敏感性扫描覆盖了关键设计参数空间 | 未覆盖下降段油门调度、翼面积、进近速度等自由度 | "覆盖了 10 个设计变量" |
| B06 | 混合电系统质量惩罚 4200 kg 可通过优化降低 | 质量系数扫描范围 150–400 kg/MW | "存在优化空间，需 V0.3 逐项核查" |

## C. 禁止声明

以下声明**绝对不得在**报告中出现：

| 序号 | 禁止声明 | 禁止原因 |
|------|----------|----------|
| C01 | "已验证的燃油消耗降低"或等效表述 | 全段可行设计为 0，表观燃油差量为约束告警状态 |
| C02 | "认证航程"或"已满足 3200 km 航程要求" | 任务求解器为准稳态概念模型，非轨迹优化 |
| C03 | "STOL 能力已实现"或"已验证的短距起降" | 起飞/着陆代理指标非认证场长，吹气襟翼为代理 |
| C04 | "噪声降低已验证"或等效表述 | 无声学模型 |
| C05 | "SAF 碳中和已验证"或"SFA 已通过认证" | SAF 为场景模型，生命周期碳排放不在本模型范围 |
| C06 | "最终可行方案已确定"或"最优设计已选出" | 全段修正可行设计为 0，所有候选为诊断性筛选 |
| C07 | "认证级模型"或"适航审定等级" | CLAUDE.md 明确 certification_grade=false |
| C08 | "氢燃料推进已具备"或"爆震推进已验证" | 两者均为未来升级路径预留（enabled=false） |
| C09 | "方案已可行"（未附带约束告警） | 需同时呈现全段修正可行设计为 0 的事实 |
| C10 | "最优方案已产生" | 尚未进行多目标优化，仅完成筛选 |
| C11 | "约束已消除"（未附带约束告警） | 下降段、起飞段、混合电未满足电负荷约束仍然存在 |
| C12 | "模型已验证"或"仿真结果已确认" | 仅完成内部一致性审计，未进行外部验证 |
| C13 | "通过 225 行参数扫描未发现可行解，说明架构本质上不可行" | 扫描未覆盖所有关键自由度（下降段油门模型等），结论方向错误 |
| C14 | "仅进近修正候选为可行设计方案" | 仅进近修正筛选有意排除非进近段约束 |
