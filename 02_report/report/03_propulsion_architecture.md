# 3. 推进架构

## 3.1 总体推进架构

MTA-VHEP 采用"双主机 + 四电动吹气襟翼风扇"的混合推进架构：

- **主推进系统**：2 台三流道变循环涡扇发动机（以下简称"主机"）
- **电动辅助系统**：4 台电动吹气襟翼风扇（以下简称"电动风扇"）

主机提供从起飞到巡航的全包线推进功率。电动风扇作为低速增升辅助，仅在起飞、初始爬升和进近阶段短时投入工作，不承担巡航主推进任务。

## 3.2 主发动机配置

| 参数 | 值 | 状态 |
|------|------|------|
| 发动机类型 | 三流道变循环涡扇 | Design Assumption |
| 数量 | 2 台 | FROZEN |
| 海平面静态推力（初始值） | 115000 N/台 | Design Assumption |
| 海平面静态推力扫描范围 | 100000–150000 N/台 | 待仿真扫描 |
| 是否支持轴功率提取 | 是 | Design Assumption |
| 第三流道模型 | 参数化模型 | Design Assumption |

主机关键设计特性：
- 三流道变循环架构：通过可变几何导流叶片和第三流道（third-stream）调节，实现多工作模式的推力-燃油效率权衡
- 轴功率提取能力：主机可向电气系统输出轴功率， penalty 已计入燃油流量模型
- 未来升级预留：支持氢燃料和爆震推进升级，但当前版本为 Jet-A/SAF 场景模型

## 3.3 电动吹气襟翼风扇配置

| 参数 | 值 | 状态 |
|------|------|------|
| 数量 | 4 台 | FROZEN |
| 功能角色 | 低速增升辅助（low-speed lift augmentation） | Design Assumption |
| 单台功率（初始值） | 1000000 W | Design Assumption |
| 总功率扫描范围 | 0–8000000 W | 待仿真扫描 |
| 风扇压比范围 | 1.05–1.25 | Design Assumption |
| 巡航状态 | 关闭或低阻力模式 | Design Assumption |
| 电机效率 | 0.95 | Engineering Inference |
| 逆变器效率 | 0.98 | Engineering Inference |

**重要声明**：电动风扇为短时低速增升辅助装置，不作为巡航主推进手段。电动风扇在巡航阶段不投入工作或仅保持最小气流通道以最小化阻力。该设计选择基于重量和功率消耗的综合权衡，不得将电动风扇的增升效果外推至巡航性能提升。

## 3.4 故障模式

电动风扇定义以下故障模式（来源：`propulsion.yaml`）：

- 单风扇失效（single_fan_failed）
- 单侧双风扇失效（one_side_failed）
- 全电动辅助不可用（all_electric_assist_unavailable）

低速度可控性分析需在故障模式下单独评估，当前版本未完成该分析。

## 3.5 参数来源

本 章所有参数标注为 **Design Assumption**，来源为 `propulsion.yaml` 配置文件。性能参数（推力、TSFC、风扇增升系数）的最终确定有待推进系统仿真模型完成后填充。
