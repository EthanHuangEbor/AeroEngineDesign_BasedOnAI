# 5. 混合电系统

## 5.1 系统架构概述

MTA-VHEP 混合电系统由以下核心组件构成：

```
主机发动机 → 发电机 → 电气总线 → 逆变器 → 电动吹气襟翼风扇
                                       ↑
                                  电池/缓冲储能
```

- **发电机（Generator）**：安装在主发动机上，将机械轴功率转化为电能
- **电气总线（Bus）**：连接发电机和电动风扇的功率传输通道
- **电池/缓冲储能（Battery/Buffer）**：在峰值功率需求时补充供电，支持短时高功率输出
- **逆变器（Inverter）**：将直流电转换为变频交流电驱动电动风扇电机
- **电动吹气襟翼风扇（Electric Fan）**：将电能转化为推力/增升气流

## 5.3 轴功率提取enalty

**重要设计约束**：主机发动机在向电气系统提供轴功率时，将产生推力损失 penalty。

当前版本的轴功率提取 penalty尚未量化（标注为 **待仿真结果填充**）。该 penalty 必须计入主机有效推力，不得忽略。轴功率提取 penalty 是混合电推进系统设计中最重要的耦合效应之一，其影响在任务仿真的各阶段均需单独评估。

## 5.4 电池/缓冲储能管理

电池/缓冲储能系统用于：
- 峰值功率补充（在电动风扇需求超过发电机可供功率时放电）
- 能量回收（进近阶段电动风扇回收部分动能）
- 应急备用（提供短时独立供电能力）

电池 SOC（State of Charge）管理策略尚未实现（标注为 **待仿真结果填充**）。SOC 剖面分析是混合电推进系统性能评估的核心输出之一。

## 5.5 电动风扇与主发动机的功率解耦

电动风扇功率需求完全由主发动机轴功率提取驱动，两者存在强耦合关系。当前版本尚未建立完整的功率解耦仿真模型，所有电动风扇功率估算均为设计假设初值。

## 5.6 参数来源

本 章参数标注为 **Design Assumption**（配置来源）或 **Engineering Inference**（基于同类系统估算）。SOC 模型、轴功率提取 penalty 等核心性能参数在仿真完成前标注为 **待仿真结果填充**。
