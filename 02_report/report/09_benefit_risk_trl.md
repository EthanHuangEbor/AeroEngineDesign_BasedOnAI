# 9. 效益、风险与技术成熟度

## 9.1 潜在效益声明

MTA-VHEP 设计概念承诺以下潜在效益，但须注意：

> **所有效益声明均为潜在收益，未经仿真验证，不得作为性能保证。**

### 9.1.1 燃油效率提升（V0.2-04 模型输出，V0.2-05/Q/Q2 敏感性诊断状态）

- V0.2-04 分段任务求解器输出显示：自适应循环方案模型燃油低于基准约 12.9%，自适应+混合电方案模型燃油低于基准约 9.3%
- V0.2-05/Q/Q2 敏感性分析（225 行）进一步显示：
  - 104 行进近约束与模型公式敏感性有关
  - 仅进近修正后 92 个案例通过基本筛选，但全段修正后可行设计数为 0
  - 全部案例的非进近段（主要为下降段）推力裕度约束仍然存在
- **自适应循环燃油趋势标记**：`conditional model trend, not verified benefit`
- **混合电结果标记**：`conditional and currently constrained by mass / electric load / all-segment margins`
- **状态**：条件性模型趋势，非已验证收益。须在 V0.3 约束消解后复核
- **不得**声称燃油消耗降低已被验证

### 9.1.2 低速增升辅助（V0.2-04 代理指标）

- V0.2-04 起飞/着陆代理指标已生成（proxy_indicator_not_certified_field_length）
- 混合电方案因 4200 kg 质量惩罚，起飞代理指标方向性差于基准方案
- **状态**：代理指标仅供方向性比较，**不得**声称 STOL 能力已被实现

### 9.1.3 噪声降低（待验证）

- 电动风扇在低速阶段提供推力辅助，有望降低主机噪音
- **状态**：`待仿真结果填充`，**不得**声称噪声降低已被证明

### 9.1.4 SAF 碳排放降低（场景模型）

- SAF 作为 Jet-A 的替代燃料有望降低生命周期碳排放
- **状态**：场景模型，**不得**声称 SAF 碳中和已被证明
- 注：生命周期碳排放核算是独立评估框架，不属于本模型范围

## 9.2 风险评估

详细风险分析见 `02_report/tables/risk_table.md`。以下是风险汇总：

### 9.2.1 高风险项

| 风险 | 描述 | 影响 |
|------|------|------|
| 推力裕度不足（V0.2-04/V0.2-05Q2） | 全部 225 个敏感性案例在全段修正后均存在 low_thrust_margin，仅进近修正后 121 个仍存在非进近段低推力 | 全段推力/阻力假设须在 V0.3 中细化 |
| 非进近推力裕度约束（V0.2-05Q2 新识别） | 下降段 197 行 + 起飞段 28 行为非进近限制段，驱动力怠速代理推力/阻力平衡 | V0.2-05Q2 最顽固的剩余约束，非设计参数扫描可消除 |
| 下降段模型/推力调度不确定性（V0.2-05Q2 新识别） | 下降段使用怠速代理推力，可能低估实际可用推力或高估需求推力 | 下降段推力裕度约 -36000 至 -42000 N，需模型级修正 |
| 起飞段剩余裕度（V0.2-05Q2 新识别） | 部分混合电高电功率案例中起飞段成为限制段 | 轴功率提取 penalty 在起飞段可能过于保守 |
| 混合电负荷未满足（V0.2-04/V0.2-05Q2） | 69 行混合电方案存在 unmet_electric_load（主导值 287117 Wh） | 功率调度或储能容量须调整，非设计参数扫描可消除 |
| 混合电负荷调度（V0.2-05Q2 新识别） | 电负荷约束独立于推力裕度分类，不受进近修正影响 | 需独立的功率调度和储能策略优化 |
| 混合电质量惩罚（V0.2-04） | 4200 kg 混合电系统质量导致起飞代理指标恶化和 MTOW 裕度紧张 | 质量预算须在 V0.3 中迭代 |
| MTOW sizing 迭代（V0.2-04） | 混合电方案 estimated MTOW 超出初始假设，距 95000 kg 上限仅余约 1357 kg | 须进行 MTOW 迭代闭合 |
| 候选类别误读风险（V0.2-05Q2 新识别） | 仅进近修正候选（92 个）可能被误读为"可行方案" | 必须明确仅进近修正筛选不等于全段可行性 |
| 敏感性模型依赖（V0.2-05Q2 新识别） | 104 行进近约束为模型公式敏感，所有约束分类依赖当前模型公式选择 | 进近模型修正可能改变约束分布 |
| 可变几何复杂度 | 可变几何机构增加发动机复杂性、重量和故障风险 | 可能影响 OEW 和可靠性 |
| 第三流道 duct/nozzle 集成 | 第三流道导管和喷管的集成设计难度大 | 可能影响变循环性能和包线 |
| 电动机器功率密度 | 当前功率密度可能不足以满足 4 × 1 MW 设计目标 | 可能限制电动风扇实际功率输出 |
| 功率电子冷却 | 高功率密度逆变器热管理挑战大 | 可能限制峰值功率持续时间 |
| 电池/缓冲热安全 | 大容量电池热失控风险 | 需要严格的热管理设计 |

### 9.2.2 中等风险项

| 风险 | 描述 | 影响 |
|------|------|------|
| 轴功率提取 effect | 轴功率提取对主机推力的影响尚未量化 | 可能显著影响有效推力 |
| 电动风扇巡航阻力 | 巡航期间关闭的电动风扇仍产生阻力 | 可能部分抵消增升收益 |
| 吹气襟翼气动不确定性 | 吹气襟翼系数为占位符，尚未验证 | 可能影响起飞性能估算 |
| 低速度可控性（故障后） | 电动风扇故障后的控制再分配尚未分析 | 可能限制故障运行包线 |

### 9.2.3 低风险/管理风险项

| 风险 | 描述 | 影响 |
|------|------|------|
| 噪声不确定性 | 噪声预测模型尚未建立 | 难以满足未来适航要求 |
| SAF 认证 overclaim | SAF 兼容性不构成碳中和或认证声明 | 需要明确场景模型边界 |
| 氢燃料 scope creep | 氢燃料作为未来升级路径存在范围蔓延风险 | 需要严格管理需求变更 |
| 爆震推进 scope creep | 爆震推进作为未来升级路径存在范围蔓延风险 | 需要严格管理需求变更 |
| 模型验证局限性 | 当前概念模型不得声称认证等级 | 需要明确模型使用边界 |
