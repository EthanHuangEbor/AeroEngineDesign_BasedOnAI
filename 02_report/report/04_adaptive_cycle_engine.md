# 4. 自适应循环发动机

## 4.1 三流道变循环概念

三流道变循环涡扇发动机（以下简称"变循环发动机"或"VCE"）通过可变几何导流叶片、可调压气机和第三流道（third-stream）旁通机构，实现单台发动机在全包线内的多模式高效运行。

相比传统双流道涡扇，变循环发动机的核心改进在于：
- **第三流道**：在低功率需求时将部分气流旁通至第三流道，减少压气机喘振裕度损失；在高功率需求时增大主流道流量
- **可变喷管**：调节喷口面积以适配不同推力需求
- **变循环调度**：通过油门、导流叶片角度和第三流道开度的联合调节，实现起飞、爬升、巡航、进近等各任务段的最优效率点切换

## 4.2 工作模式定义

变循环发动机定义以下工作模式（来源：`propulsion.yaml`）：

| 模式 | 油门设置 | 第三流道调度 | 可变喷管调度 |
|------|----------|--------------|--------------|
| 起飞（takeoff） | 1.00 | 0.10 | 0.85 |
| 爬升（climb） | 0.88 | 0.15 | 0.70 |
| 巡航（cruise） | 0.65 | 0.40 | 0.55 |
| 进近（approach） | 0.35 | 0.50 | 0.45 |
| 怠速（idle） | 0.10 | 0.30 | 0.40 |

## 4.4 氢燃料与爆震推进预留

变循环发动机设计支持氢燃料和爆震推进升级作为未来升级路径，但当前版本：
- `future_hydrogen_enabled: false`
- `future_detonation_enabled: false`

氢燃料与爆震推进相关性能分析不计入本报告，不得声称飞机已具备氢动力或爆震推进能力。
